集成代码示例

# api/app/agent_service.py ← Atlas 新增模块
from openhands.sdk import Agent, Conversation, Tool, LLM
from openhands.tools.file_editor import FileEditorTool
from openhands.tools.terminal import TerminalTool

async def run_coding_agent(task: str, workspace: str):
  agent = Agent(
    llm=LLM(model="gpt-4.1"),
    tools=[
      Tool(name=FileEditorTool.name),
      Tool(name=TerminalTool.name),
    ]
  )
  conv = Conversation(agent=agent, workspace=workspace)

  # SSE 流式输出到 Atlas 前端
  async for event in conv.stream(task):
    yield event # → React 页面实时渲染

⚠️ 唯一的不兼容点 — 可以改 Atlas 适配

🐳
Docker		 OpenHands 需要 Docker 做沙箱执行。Atlas 后端需要一个 Docker daemon。
影响：Atlas 的 docker-compose.yml 里加一个 OpenHands 服务定义，或者 Atlas 后端直接调用 Docker SDK。
🔑
认证		 OpenHands SDK 需要 LLM API Key。Atlas 目前没有用户认证。
影响：P1 或 P2 加点工作量，加一个简单的 API Key 管理。
📦
文件		 OpenHands 操作的是 Docker 容器内的文件系统。前端需要文件树。
影响：React 前端增加一个文件浏览组件（1天）。

这些问题都不是架构冲突 — 属于集成时的正常适配工作，已经包含在 5-7 天的估算里。
