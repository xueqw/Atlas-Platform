🛤 分三期实施路线

P1

第一期 · 智能体体系 (核心)

Agent 模型 + CRUD API + 列表页 + 配置编辑器 + 测试对话。打通端到端的智能体管理闭环。

后端：4-6 个 API · 前端：2 个页面 · 预估 2-3 天

P2

第二期 · 资源中心 (知识库 + 工具 + 模型)

Document/Tool/ModelConfig 三张表 + 对应 API + 前端页面。让智能体可连接知识与工具。

后端：10+ API · 前端：3 个页面 · 预估 3-4 天

P3

第三期 · 平台增强 (Skills + 报表 + 权限)

Skills 系统、数据报表、用户认证与 RBAC。从工具平台升级为可运营的企业产品。

后端：认证体系 + Skills API · 前端：2-3 个页面 · 预估 4-5 天
