# M3 Skill Hub Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let the agent auto-select instruction-type skills (Strategy Agent as router) and let users force-enable skills via a searchable multi-select in the chat composer; selected skills inject methodology into the answer step and are recorded in the run.

**Architecture:** A new `skills` table (workspace-scoped, with seeded builtins) backs a Skill Hub CRUD page and a composer dropdown. `skills_engine.py` holds two pure functions (resolve = manual ∪ auto; build instructions). `strategy.plan()` is extended into a skill router that picks from a name+description catalog (progressive disclosure). `send_message` resolves manual ∪ auto, injects skill content into the respond step, emits `skills_selected`, and persists the resolved list into `plan_json`.

**Tech Stack:** FastAPI + SQLAlchemy 2.0 + SQLite (backend), pytest + Starlette TestClient (tests), React + TS + Vite (frontend). Backend venv: `api/.venv/Scripts/python.exe`.

## Global Constraints

- All skill data is **workspace-scoped**; every query filters by `workspace_id` (tenant isolation, never leak across workspaces). Copy the existing pattern from conversations/agents in `api/app/main.py`.
- Skill `type` is `instruction` only this milestone. Do not add workflow/tool-backed/code.
- Manual ∪ auto is a **union**: manual selections are always included; auto adds more. Manual never restricts auto.
- Builtin skills are **read-only**: PUT/DELETE on a builtin → HTTP 403.
- Strategy Agent must **degrade safely**: any planning error or empty catalog ⇒ `plan["skills"] = []`, never block the chat.
- Progressive disclosure: the catalog handed to the router contains only `{id, name, description, trigger_phrases}` — **never `content`**. Content is injected only for resolved skills.
- Run backend commands with `api/.venv/Scripts/python.exe`; run from `api/` so `app` is importable. Frontend commands run from `web/`.
- Chinese UI copy, matching existing components.

```python
"""Skill Hub 运行时纯逻辑（PRD M3）。无 db / 无网络，便于单测。"""


def resolve_skills(catalog: list[dict], manual_ids: list[str], auto_ids: list[str]) -> list[dict]:
    """手动(强制) ∪ 自动 → 标 source、去重、仅保留 catalog 内的 id。
    手动在前，自动补后；同时命中按手动算。"""
    by_id = {s["id"]: s for s in catalog}
    out: list[dict] = []
    seen: set[str] = set()
    for sid in list(manual_ids) + list(auto_ids):
        if sid in seen or sid not in by_id:
            continue
        seen.add(sid)
        s = by_id[sid]
        out.append({
            "id": s["id"], "name": s["name"], "content": s.get("content", ""),
            "source": "manual" if sid in manual_ids else "auto",
        })
    return out
```

```python
def build_skill_instructions(selected: list[dict]) -> str:
    """把选中 skill 的正文拼成一条系统消息；空列表返回 ''。"""
    if not selected:
        return ""
    blocks = [f"【{s['name']}】\n{s.get('content', '')}".strip() for s in selected]
    return "技能指引（请遵循以下方法论与输出格式）：\n\n" + "\n\n".join(blocks)
```

```python
def seed_builtin_skills() -> None:
    with SessionLocal() as db:
        workspaces = db.scalars(select(Workspace)).all()
        for ws in workspaces:
            existing = {
                s.name for s in db.scalars(
                    select(Skill).where(Skill.workspace_id == ws.id, Skill.builtin == True)  # noqa: E712
```

```python
@app.get("/api/skills", response_model=list[SkillOut])
def list_skills(ws: str = Depends(current_workspace_id), db: Session = Depends(get_db)):
    return db.scalars(select(Skill).where(Skill.workspace_id == ws).order_by(Skill.builtin.desc(), Skill.created_at)).all()


@app.post("/api/skills", response_model=SkillOut, status_code=201)
def create_skill(payload: SkillCreate, ws: str = Depends(current_workspace_id), db: Session = Depends(get_db)):
    skill = Skill(workspace_id=ws, type="instruction", builtin=False, **payload.model_dump())
    db.add(skill); db.commit(); db.refresh(skill)
    return skill


def _get_owned_skill(skill_id: str, ws: str, db: Session) -> Skill:
    skill = db.scalar(select(Skill).where(Skill.id == skill_id, Skill.workspace_id == ws))
    if not skill:
        raise HTTPException(404, "技能不存在")
    return skill


@app.get("/api/skills/{skill_id}", response_model=SkillOut)
def get_skill(skill_id: str, ws: str = Depends(current_workspace_id), db: Session = Depends(get_db)):
    return _get_owned_skill(skill_id, ws, db)


@app.put("/api/skills/{skill_id}", response_model=SkillOut)
def update_skill(skill_id: str, payload: SkillUpdate, ws: str = Depends(current_workspace_id), db: Session = Depends(get_db)):
    skill = _get_owned_skill(skill_id, ws, db)
    if skill.builtin:
        raise HTTPException(403, "内置技能只读")
    for k, v in payload.model_dump().items():
        setattr(skill, k, v)
    db.commit(); db.refresh(skill)
    return skill


@app.delete("/api/skills/{skill_id}")
def delete_skill(skill_id: str, ws: str = Depends(current_workspace_id), db: Session = Depends(get_db)):
    skill = _get_owned_skill(skill_id, ws, db)
    if skill.builtin:
        raise HTTPException(403, "内置技能只读")
    db.delete(skill); db.commit()
    return {"ok": True}
```
